# Git Tutorial

Practising Git and GitHub basics.

## Tasks
1. **Version 1:** Push a local project to GitHub.
2. **Version 2:** Clone, create a feature branch, and merge into `main`.
3. **Switch Versions:** Move from version 2 to version 1.
4. **Merge Conflicts:** Create and resolve conflicts.
5. **Undo Changes:** Practise reset and revert.
6. **Branching:** Create, switch, merge, and delete branches.

## Technologies
- HTML
- Git
- GitHub
